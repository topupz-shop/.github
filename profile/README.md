### 🛠️ For developers and resellers

**[SupercellTopupAPI](https://github.com/topupz-shop/SupercellTopupAPI)**: a REST API to sell Supercell top-ups from your own site or bot. You can read the catalog, place orders from your wallet, submit login codes and get webhooks.

```bash
curl https://api.topupz.shop/api/v1/reseller/balance -H "X-API-Key: tpz_your_api_key"
```
